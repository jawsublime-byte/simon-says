# Security

Use Red Rover, Battleship, Dodgeball, Heads Up Seven Up, and Sand Castles only on systems you own or are authorized to test.

Never include real credentials, production secrets, private user data, destructive payloads, persistence, evasion, or third-party targets in examples, evaluations, or reports.

Report a repository vulnerability through GitHub private vulnerability reporting. Do not open a public issue containing an unpatched exploit or secret.
